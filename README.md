# CGGL

Welcome to my passion project, CGGL!

## SIQ (Super Important Questions)

#### What's this?

CGGL is an all-purpose C++ library, which currently has the following core features:
- Math (Vectors)
- Graphics
- Basic shape drawing
- Textures
- Text
- Input
- GUI
- Audio (with miniaudio)

It also has the following optional features:
- (in the future realtime) Raytracing

To be added features:
- A simple helper header file for video decoding with FFmpeg

#### What does CGGL stand for?

Cat's Graphics & GUI Library. It started out as a library only meant for graphics and GUI, but that changed and I like the name so im keeping it.
